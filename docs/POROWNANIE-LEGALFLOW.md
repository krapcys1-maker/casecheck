# CaseCheck a LegalFlow — ponowny przegląd 3.10.2026

Podstawą jest dokładnie [legal-flow.pl/#produkt](https://legal-flow.pl/#produkt), pełna treść oraz pięć ekranów od użytkownika. Wcześniejszy przegląd innej strony Booster AI nie wystarczał. Ich ilustracyjny scenariusz nie daje dostępu do działającego produktu ani porównywalnej próby odpowiedzi.

**Nie osiągnęliśmy całego deklarowanego procesu LegalFlow.** Wcześniejsze zapewnienie „wszystko działa” było zbyt szerokie. Nasza „Rozmowa” do tej zmiany była formularzem z ekstrakcją AI i stałym kolejnym pytaniem. Teraz jest czatem z kontekstem, lecz automatyzacja pozostaje częściowa.

| Ekran | Deklaracja LegalFlow | CaseCheck po zmianie |
|---|---|---|
| Asystent AI | Swobodna rozmowa, dopytywanie, pobranie MF/KRS po NIP | Rozmowa DeepSeek, kontekst, korekty, cytowane ustalenia. MF/KRS uruchamia pracownik; NIP z rozmowy nie uruchamia rejestru. |
| Sprawa | Zapis podczas rozmowy, źródło, pewność, widok na żywo | „Nowa rozmowa z asystentem” tworzy sprawę. Panel danych aktualizuje się po odpowiedzi. Druga sesja widzi powiadomienie i odświeża z zachowaniem tekstu. Brak anonimowego zakładania spraw i skalibrowanych procentów pewności. |
| Pisma | Automatyczne projekty po wywiadzie, akceptacja z historią | Projekty, własne wzory, wersje, akceptacja, PDF/DOCX. Generowanie nadal wymaga kliknięcia pracownika. |
| Etapy i zadania | Etap uruchamia pisma, zadania, terminy i skonfigurowany e-mail | Ręczne etapy, zadania, osoby i daty. Powiadomienia w aplikacji i przypomnienia. Brak automatycznego pakietu etapu i wysyłki e-mail/SMS. |
| Konsument | Dziesięć obszarów wniosku z przeglądem | Pytania o sytuację, długi, spory, majątek, zabezpieczenia, przychody i czynności. Brak pełnego przebiegu sąd/COMI/oświadczenie i gotowego urzędowego wniosku. |
| KRZ | Integracja przygotowywana | Brak bezpośredniej integracji; u konkurenta również jest zapowiedzią. |

[Ręczny odbiór czatu](RECZNY-ODBIOR-CZATU.md) opisuje rzeczywiste wywołania, znalezione błędy i poprawki. Próby na fikcyjnych danych nie mierzą trafności na realnych aktach ani przewagi nad konkurentem. Nasza kontrola cytatów, przegląd OCR, historia, blokowanie nieaktualnych pism i odzyskiwanie wyniku bez drugiego API są demonstracją działających funkcji. Nie wiemy, czy LegalFlow nie ma podobnych zabezpieczeń.

Dalsza kolejność: pobranie firmy po NIP; osobne rekordy wierzycieli z rozmowy i uzgodnienie z dokumentami; zakończenie wywiadu z projektami do przeglądu; konfigurowalne reguły etapów; odbiór całego procesu konsumenckiego przez prawnika. Nie zastępujemy braków atrapami integracji.

KRZ odłożono zgodnie z dyspozycją użytkownika. [FAQ Ministerstwa Sprawiedliwości](https://www.gov.pl/web/sprawiedliwosc/faq3) opisuje jawny i bezpłatny dostęp dla każdego oraz API nadal jako planowane. Firma nie jest warunkiem samego przeglądania publicznych informacji.
